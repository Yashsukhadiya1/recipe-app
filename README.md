# Food Recipe App

A React app that lets you search for meal recipes using the [TheMealDB API](https://www.themealdb.com/).

## Features

- Search any dish by name
- Browse meal cards with images and names
- Click on a meal to view its full recipe and step-by-step instructions

## Tech Stack

- React
- React Router DOM
- TheMealDB public API

## Getting Started

```bash
npm install
npm start
```

## Usage

1. Type a dish name in the search bar and click **Search**
2. Browse the results and click **Recipe** on any meal card
3. View the full recipe details and cooking instructions
